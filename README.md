# Thai Lottery Analytics

วิเคราะห์สถิติหวยไทย (เลข 2 ตัว / 3 ตัว) และหวยมาเลย์ Magnum 4D (รางวัลที่ 1–3) จากผลรางวัลจริงย้อนหลัง พร้อมทดสอบย้อนหลังเทียบกับการสุ่ม

เปิดใช้งาน: https://anchittha-sky.github.io/thai-lottery-analytics/

- `index.html` ตัวแอป
- `data.js` ผลหวยไทยและเลขสำนัก (อัปเดตอัตโนมัติ)
- `data4d.js` ผล Magnum 4D รางวัลที่ 1–3 (อัปเดตอัตโนมัติ)

แหล่งข้อมูล: github.com/vicha-w/thai-lotto-archive, github.com/deadboy18/malaysia-4d และข่าวเลขเด็ดที่เผยแพร่ก่อนวันออกรางวัล

คะแนนในแอปเป็นการสรุปข้อมูลย้อนหลัง ไม่ใช่ความน่าจะเป็นในการถูกรางวัล
